Loads a guinea application's localisation before the first render, and
remembers the language the user picked.

```rust
guinea::app::GuineaApp::new()
    .plugin(guinea_plugin_store::StorePlugin::for_app("my-app", "settings"))
    .plugin(guinea_plugin_l10n::L10nPlugin::<L10n>::new("en"))
```

`L10n` here is the resolver generated by `fluent_loader!`; the plugin works
with any type implementing `Localization`, which the loader implements for
you.

The language is state the application owns: the plugin claims
`Language<L10n>` and exports it to every window. A page or a layout reads
it, and is drawn again when it changes:

```rust
use guinea_plugin_l10n::L10nAccess;

let strings = cx.l10n::<L10n>();
```

That works on the pages and layouts of WinUI, eframe, ratatui and iced. Slint
binds its view once rather than reading it as it draws, and is not one of
them: read `Language<L10n>` there as any other state.

A switch is taken from the page, without reading - so the page is not drawn
again for it - and kept in a callback:

```rust
let switch = cx.language_switch::<L10n>();
Button::new().on_click(move || switch.to("ru"))
```

A tag the application has no strings for leaves the language as it was.

Where a plugin or a feature is installed, `L10nSetup` reads the language
once, and `observe::<Language<L10n>>` hears every switch after:

```rust
use guinea_plugin_l10n::L10nSetup;

let strings = cx.l10n::<L10n>();
```

## Persistence

With the default `persist` feature the plugin restores the language saved on
the previous run and saves every subsequent change, using
[`guinea-plugin-store`](../store). The store must be installed first; if it is
not, the plugin warns and falls back to the default tag.

Turn it off with `.persist(false)`, or by disabling default features.

## Language tags

Tags are BCP-47 (`"en"`, `"ru"`, `"pt-BR"`). An unusable saved tag falls back
to the default and warns; an unusable *default* tag is an installation error.
